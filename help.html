1这是什么

一句话：把学习通账号托管给「马上签」，老师发起签到时自动帮你完成，并邮件通知你。

「马上签」是一个多用户的超星学习通自动签到系统。每个用户用手机号/用户名注册站点账号后，通过扫码绑定自己的学习通账号（无需账号密码），系统即为该账号启动独立监控线程，每 45 秒巡查一次课程；一旦老师发起签到，自动完成普通、手势、位置、签到码类签到，二维码和拍照类签到则立即推送邮件提醒你手动完成。

能力说明
自动签到普通 / 手势 / 位置 / 签到码 四种类型全自动完成
手动提醒二维码、拍照类签到自动识别，秒发 QQ 邮件提醒
持续监控每账号独立线程 + 看门狗自动重启，服务重启后自动恢复监控
课程管理自动拉取课程列表，可勾选只监控部分课程，支持一键刷新
邮件通知签到成功、失败、需手动、登录过期、欢迎邮件，全部走 QQ 邮箱
多账号一个站点账号可绑定多个学习通账号，各自独立监控
工单系统内置反馈工单，管理员在线回复
公告系统系统公告展示在主页顶部，用户可关闭

2三分钟快速开始

整个使用流程只有三步：

注册站点账号打开 xxt.leich.cn，用用户名 + 密码 + QQ 邮箱注册（邮箱用于接收签到通知，必填）。
扫码绑定学习通进入「我的账号」→ 点右上角 + 添加学习通账号 → 用学习通 App 扫二维码并确认 → 账号自动出现，监控自动开启。
放着不管之后每次老师发起签到，系统自动处理并给你的 QQ 邮箱发信；需要手动操作的（二维码/拍照）也会邮件提醒你。
绑定成功后监控默认开启且保持在线，无需任何额外操作。若登录态过期（Cookie 通常 30 天有效），系统会邮件提醒你重新扫码。

3用户端使用教程

用户端地址：http://xxt.leich.cn（手机浏览器同样可用，界面自动适配）。

3.1 注册与登录

打开首页即登录/注册页。首次使用点「注册」标签：

  • 用户名：2-32 位字母、数字、_ 或 -；
  • 密码：任意（建议 6 位以上）；
  • QQ 邮箱：必填，用于接收签到通知邮件（不验证邮箱真实性，但填错将收不到通知）。
注册页：用户名 + 密码 + QQ 邮箱（必填）
登录页

注册成功会自动登录。之后访问首页点「登录」标签即可。登录成功后同样会收到一封欢迎邮件。

3.2 添加学习通账号（扫码）

登录后进入「我的账号」页，点右上角 + 添加学习通账号：

扫码添加学习通账号
  1. 弹窗会显示一个二维码（有效期约 10 分钟，过期点「刷新二维码」）；
  2. 打开手机学习通 App → 右上角「邀请码」旁的扫一扫（或 App 内二维码扫描）扫描该码；
  3. 手机上点确认后，网页提示「添加成功」，账号卡片出现，监控自动开启。
扫码即代表你把该学习通账号授权给本站，无需输入学习通密码。同一个学习通账号被多个站点用户扫码时，归属权转移给最后扫码的人。

3.3 账号卡片与配置

「我的账号」页展示你所有的学习通账号卡片：

我的账号：账号卡片与监控开关
  • 卡片右上角显示登录状态（已登录 / 未登录 / 需重新登录）；
  • 卡片内可看到监控状态、课程数、签到记录数、今日需手动次数；
  • 底部 监控 开关可随时暂停/恢复监控；
  • 卡片底部三个图标依次为：配置/记录（齿轮）、退出该学习通账号、移除账号。

点齿轮图标打开详情抽屉，默认在「配置」页：

账号详情抽屉：配置页
配置项说明
检测间隔（秒）每轮巡查的等待时间，默认 45 秒。间隔越短发现签到越快，但过于频繁可能被学习通限频（系统检测到限频会自动降频）
Server 酱 SendKey可选。填写后可额外通过微信推送通知（不填只发 QQ 邮件）
仅监控以下课程默认监控全部课程；可只勾选需要的课程，减少无效请求
刷新课程从学习通重新拉取最新课程列表。新选课程看不到时点它

3.4 查看签到记录

点账号卡片上的「查看记录」，或在详情抽屉切到「签到记录」标签：

签到记录

记录包含：科目、活动名称、签到类型、结果（成功/失败/需手动）、时间与详情。最多保留最近 200 条。

3.5 个人主页

「个人主页」是你的个人中心：

个人主页：个人中心 / 统计 / 工单 / 版本信息
  • 个人中心卡片：展示用户名、QQ 邮箱、角色、注册时间；点右上角「编辑资料」可修改 QQ 邮箱和密码；
  • 统计卡片：学习通账号数、在线数、监控中数量、我的工单数；
  • 我的工单：提交反馈、查看回复；
  • 版本信息：当前系统版本与公告。

3.6 提交工单（反馈问题）

在个人主页点「+ 提交工单」，选择类型（故障/BUG、功能建议、使用咨询、其他）、填写标题和内容即可。管理员回复后可在工单对话中继续沟通。

4邮件通知说明

所有通知均发送到你注册时填写的 QQ 邮箱，发件人为系统 QQ 邮箱。

邮件触发时机
欢迎使用马上签注册成功、每次登录成功时
自动签到成功检测到签到活动并自动完成
自动签到失败自动签到请求返回异常（附失败原因）
需手动完成签到二维码签到（需你扫码）
拍照签到提醒老师发起的是拍照签到（需相机完成）
监控暂停提醒学习通登录态过期，需重新扫码
邮件为 HTML 精美排版，包含科目、活动、时间等关键信息，手机 QQ 邮箱可直接查看。
若收不到邮件：① 检查个人主页的 QQ 邮箱地址是否填错（填错可在「编辑资料」里修改）；② 查看垃圾邮件箱；③ 通过工单联系管理员确认通知是否正常。

5签到类型与自动化规则

签到类型处理方式说明
普通签到 自动直接调用签到接口完成
手势签到 自动自动完成
位置签到 自动使用你账号在配置中的位置信息；不在范围内会失败并邮件告知
签到码 自动输入教师公布的签到码即可自动完成
二维码签到 邮件提醒需本人扫码，无法代劳；系统检测到后立即发邮件
拍照签到 邮件提醒需相机拍照，系统发邮件提醒手动完成

同一签到活动只会处理一次（内置去重），不会重复签到；「您已签到过了」的返回也会被识别为成功。

6常见问题 FAQ

Q1：添加账号后提示成功，但列表里看不到？

多为该学习通账号此前被其他站点用户绑定过。再次扫码会把归属权转移给当前扫码者。若仍未出现，刷新页面重试。

Q2：监控显示在线，但签到没有自动完成？

依次检查：① 是否勾选了该课程（详情 → 配置 → 仅监控以下课程，留空=全部）；② 账号是否「需重新登录」；③ 「签到记录」里查看失败记录及原因；④ 若以上都正常，可通过工单反馈给管理员排查。

Q3：新选的课程在列表里看不到？

点账号详情 → 配置 → 「刷新课程」，从学习通重新拉取。监控线程每 10 分钟也会自动刷新一次。

Q4：收不到邮件怎么办？

检查个人主页的 QQ 邮箱是否正确 → 查看垃圾邮件 → 通过工单联系管理员确认。

Q5：账号显示「需重新登录」？

学习通 Cookie 过期（通常 30 天）。退出该账号后重新扫码即可，配置与历史记录都会保留。

Q6：服务器重启后监控还在吗？

在。服务重启会自动恢复所有账号的登录态并重启监控（只要「监控」开关此前是开启状态）。

Q7：一个账号可以绑多个学习通账号吗？

可以，站点账号与学习通账号是一对多关系，各自独立监控。

7注意事项

  • 本工具仅供学习交流，请勿用于违纪作弊或商业用途；
  • 二维码/拍照类签到按设计只能手动完成，请及时查看邮件提醒；
  • 请勿把检测间隔设置得过小（<15 秒），频繁请求可能被学习通限频甚至封禁账号；
  • 学习通登录态约 30 天过期，收到「监控暂停提醒」邮件后请尽快重新扫码；
  • 系统当前为 http 协议，请勿在公共网络保存密码，管理员后续会配置 HTTPS。
